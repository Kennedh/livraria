# 📚 Sistema de Gestão de Livraria

Sistema de console em Python para gestão de livraria, desenvolvido com Programação Orientada a Objetos (POO). 
Controla estoque, registra vendas e gera relatórios financeiros.

## ✨ Funcionalidades

- **Gestão de Produtos**: Cadastro com SKU, título, preço de venda e custo
- **Controle de Estoque**: Adição, remoção e consulta de disponibilidade
- **Registro de Vendas**: Transações com cliente, itens, valor total e lucro
- **Relatórios**: Estoque e vendas com faturamento e lucro bruto
- **Validações**: Preços, ISBN, estoque insuficiente, etc.
- **Arquitetura extensível**: Fácil adaptar para outros tipos de produtos
